# 使用 Mesh Dock

在 Blender 3D 视图按 `N`，打开 **Mesh Dock** 页签，再点击 **打开 AI 工作区**。工作区沿用当前场景；模型仍可使用 Blender 的选择、编辑、删除、撤销和导出操作。

## 生成模型

1. 在左侧 **平台** 添加账号。**获取 Key** 会打开对应平台的密钥页面。
2. 回到 **生成**，选择平台账号和模型，再选择 **单图／多视图／文字**。
3. 添加参考图或描述，按需展开 **几何与拓扑**、**材质与贴图**、**高级**。
4. 查看确认窗口里的输入、数量和费用预估，确认后提交。

多视图入口会随模型变化。带 `*` 的视图为必需项。切换输入方式会保留各自的草稿；不兼容的视图不会提交。

生成完成后，结果会加入发起任务时的场景。一次生成多个模型时，每个结果使用独立 Collection。在左侧 **历史** 中可以查找结果；已删除的结果只有在主动点击历史记录时才会重新导入。

## 处理现有模型

在物体模式中选中一个网格，再打开 **重拓扑**、**处理** 或 **动画**。处理前可在左侧设置服务、目标面数等参数。提交会生成一个新结果，原物体留在场景中。

对于 Mesh Dock 生成的模型，选中其中一个部件会处理它所属的完整结果，不会影响同批生成的其他结果。对于自行建模或导入的模型，只处理当前活动且选中的网格；即使同时选中多个物体也一样。确认窗口会显示并锁定本次目标。

生成结果若在导入后完全没有改动，可以复用其原始来源。几何、材质、变换、修改器或部件变化后，插件会导出当前模型并重新上传。自建模型也走这一流程。可用操作取决于服务商是否支持本地模型输入。

本地上传使用 GLB 快照，包含求值后的几何、变换及 GLB 支持的材质；不会把完整 Blender 材质节点自动烘焙，也不包含动画或骨架。修改过的绑定模型应先重新绑定，再使用服务商的动作生成功能。

## 账号、任务与导出

**平台** 页可管理账号、打开密钥页面。Tripo 账号可主动检查授权和余额；其他账号的本地启用状态不代表已在线验证。

运行中的任务会显示在当前面板。停止本地任务可能只停止轮询或下载，远端任务仍可能继续运行并计费。

结果可使用 Blender 的 **文件 > 导出**；历史结果也提供右键导出入口。模型和历史不会替用户建立额外的资产目录。
